# VIST-AI Protocol MVP
A foundational Python-based prototype for **Visual-Geometric Computation** and **Forensic Evaluation** to detect AI distortions and ensure model governance.
## Features
- Geometric consistency checks using mathematical distance metrics.
- Automated flagging of suspicious or deepfake-generated visual outputs.
- Lightweight MVP structure designed for enterprise and academic extension.
